# MuseoHub

**Repository di lavoro per il Project Work L-31 Pegaso.**

MuseoHub è un prototipo web full-stack pensato per supportare la digitalizzazione di alcuni processi gestionali di una piccola realtà museale simulata.
Il progetto si concentra sulla gestione integrata di eventi o servizi culturali, prenotazioni dei visitatori, raccolta dei feedback e consultazione amministrativa dei dati tramite dashboard minima, API REST e database relazionale.

## Stato del progetto

Progetto in fase iniziale di analisi e progettazione.
