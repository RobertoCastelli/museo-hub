## Tema

## Traccia

**Traccia del PW 22:**  
Digitalizzazione dei processi aziendali in un’impresa culturale: progettazione di una piattaforma informatica per la gestione di servizi, dati e utenti.

---

## Descrizione situazione-problema

Le imprese e le organizzazioni che operano nell’ambito della cultura, quali musei, fondazioni, biblioteche, archivi, gallerie, teatri ed enti di promozione culturale, sono oggi coinvolte in un processo di trasformazione digitale che riguarda la gestione dei servizi, dei dati e delle relazioni con gli utenti.

In molte realtà, soprattutto di piccole e medie dimensioni, attività come la prenotazione di eventi, la catalogazione dei contenuti, la gestione dei visitatori, la raccolta dei feedback e il monitoraggio delle attività sono ancora svolte mediante strumenti frammentati, quali fogli di calcolo, email, moduli cartacei o applicazioni non integrate.

Questa situazione può generare inefficienze operative, difficoltà nella condivisione delle informazioni e limitata capacità di valorizzare i dati prodotti dall’organizzazione.

Il Project Work richiede allo studente di progettare e sviluppare un prototipo di piattaforma digitale per un’impresa culturale, finalizzato alla digitalizzazione di uno o più processi aziendali significativi.

Il lavoro dovrà avere come nucleo tecnico l’area INF/01, con particolare riferimento all’architettura dei calcolatori e alla progettazione di sistemi applicativi.

Lo studente dovrà quindi collegare i concetti di elaborazione, memorizzazione e comunicazione dei dati alla realizzazione di un sistema composto da:

- interfaccia utente;
- backend;
- database;
- API.

---

## Obiettivi

Lo studente sarà in grado di:

- Analizzare un processo aziendale di un’impresa culturale da digitalizzare.
- Progettare una semplice architettura applicativa composta da front-end, back-end, database e API.
- Applicare concetti di architettura dei calcolatori alla gestione di dati, elaborazione e comunicazione tra componenti.
- Implementare un’applicazione web utilizzando HTML, CSS e JavaScript per la parte front-end, anche tramite framework.
- Utilizzare Python, Java o altro linguaggio object-oriented per creare un semplice back-end API relativo ai casi d’uso selezionati.
- Realizzare una base dati per la gestione di utenti, servizi culturali, prenotazioni, cataloghi o feedback.
- Documentare il prototipo mediante diagrammi, descrizione tecnica, API e test funzionali.

---

## Elaborato / Artefatto / Prodotto

L’elaborato finale dovrà consistere in un prototipo di piattaforma digitale per la gestione di uno o più processi aziendali di un’impresa culturale reale o simulata.

Il sistema potrà riguardare, ad esempio, la gestione di:

- un museo;
- una biblioteca;
- un archivio digitale;
- una fondazione;
- una galleria;
- un teatro.

La piattaforma potrà prevedere funzionalità quali:

- gestione di un catalogo digitale;
- prenotazione di visite o eventi;
- amministrazione degli utenti;
- raccolta di feedback;
- produzione di una semplice dashboard con indicatori sulle attività svolte.

Dal punto di vista tecnico, l’artefatto dovrà comprendere:

- front-end web;
- backend applicativo;
- base dati relazionale;
- API per la comunicazione tra le diverse componenti.
